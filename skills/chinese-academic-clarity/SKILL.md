# 中文学术防御性写作修复

## 任务边界

把“防御性写作”视为一种文本输出倾向：作者或模型优先回避潜在质疑，导致中心判断被限定语、平衡句和免责声明遮住。不要把它描述成模型内部真实存在的开关或隐藏参数。

本 Skill 只处理段落层面的诊断、改写和审查。不得虚构事实、数据、访谈、案例、文献或因果关系；不得把证据没有支持的判断写得更强；不得承诺绕过 AI 检测。

## 识别防御性信号

先判断文本是否出现以下一种或多种情况：

1. 段落主要在回应尚未出现的质疑，研究判断迟迟不进入主线。
2. 频繁使用“并非……而是……”“不能简单认为……”“既……又……”等整齐句壳，却没有增加新的分析关系。
3. “可能”“一定程度上”“某种意义上”“相对而言”等限定语连续叠加，读者仍不知道作者究竟判断了什么。
4. 技术、主体、制度、环境等抽象名词被平行罗列，各因素之间没有主次、方向或作用过程。
5. 每段重新介绍背景、重述题目或做宏观总结，没有承接当前段落已经形成的认识。
6. 结尾只说“需要综合分析”“具有重要意义”“值得进一步关注”，没有落到可研究的问题。

出现某个词不等于存在问题。只有当表达遮住中心判断、没有信息增量，或使证据关系变得含混时，才进行修复。

## 执行流程

### 1. 恢复最小上下文

在内部确认以下信息：

- 当前文本的体裁与章节位置；
- 这一段要解决的具体问题；
- 用户已经提供的事实、材料和概念；
- 前文已经完成的判断与本段应新增的认识；
- 哪些内容只是推论，哪些边界必须保留。

缺少上下文时，不自行补造。若用户要求示范，明确按“结构示范”处理，并把判断强度控制在现有材料允许的范围内。

### 2. 找出被遮住的判断

用一句内部工作句回答：

```text
基于现有材料，这一段最值得作者承担的判断是什么？
```

如果无法回答，先指出材料只支持问题提出、关系假设或机制线索中的哪一层，不强行生成结论。

### 3. 划分信息强度

在内部区分：

- 已有事实或材料直接显示的内容；
- 从材料可以合理推出的解释；
- 尚待验证的关系；
- 会改变读者理解的必要边界。

正文中的语气必须与信息强度匹配。真实的不确定性要保留，但只在它影响判断成立范围的位置出现一次。

### 4. 重写主线

优先采用以下关系组织句子：

```text
具体主体 → 采取或经历什么行动 → 经过什么过程 → 产生什么结果 → 说明什么研究问题
```

能够写出主体、事项、行动和过程时，不用“多重因素”“复杂影响”“综合作用”等词代替分析。必要时允许短句，不追求句式对称。

### 5. 压缩防御性外壳

- 删除只用于显得稳妥、删去后不改变含义的限定语。
- 将否定对偶改成直接陈述，除非对照本身就是研究发现。
- 将并列因素改为有方向的关系；材料不足以确定关系时，保留问题形式。
- 将免责声明移到真正影响解释的位置，不在段首反复预防质疑。
- 删除宏观总结壳，让段尾回到本段形成的具体认识或下一步问题。

### 6. 做四项审查

1. **删除检验**：删掉限定语后，句义是否没有变化？若是，删除。
2. **证据检验**：每个事实判断是否能回到用户提供的材料？若不能，降为待验证问题或删除。
3. **替换检验**：把研究对象换成另一领域后，整段是否仍然成立？若是，继续具体化。
4. **边界检验**：保留下来的限定是否真的改变判断范围？若否，压缩。

## 输出方式

- 用户要求“只输出改写”：只给修订后的正文，不解释流程。
- 用户要求“诊断”：依次给出“被遮住的判断”“防御性触发点”“改写稿”。
- 用户要求“前后对比”：保留原文，给出改写稿，并用不超过三条说明关键变化。
- 用户只提供题目而没有材料：输出结构示范，并清楚标注不能形成事实结论。

## 写作纪律

- 保留真实冲突、反例、负面结果和材料中的含混，不把复杂经验改成顺滑故事。
- 不以“去 AI 味”为由制造口语化、情绪化或故意不通顺的表达。
- 不机械禁用某个词。判断表达在当前句中的功能，再决定保留、移动或删除。
- 不用新的宏观套话填补被删去的旧套话。
- 不把上下文读取过程写进正文。章节承接通过研究对象、材料结果、作用过程和未决问题自然呈现。
