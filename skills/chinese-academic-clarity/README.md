# 中文学术防御性写作修复

技能名：`chinese-academic-clarity`。

## 用途

帮助作者把中文学术段落中被限定语、整齐句壳和重复免责声明遮住的判断写清楚，让材料、解释和结论之间的关系更直接。

这里的“防御性写作”指一种文本表达倾向，不指模型内部的开关或隐藏参数。技能按句子和段落的实际功能判断问题，不机械禁用“可能”“并非”等词。

完整执行规则见 [SKILL.md](SKILL.md)。

## 适用场景

- 论文、研究报告或技术文稿的段落润色。
- 判断被连续限定语或预防性质疑遮住，需要恢复论述主线。
- 段落反复交代背景、平行罗列抽象因素，却缺少具体作用过程。
- 需要诊断问题或给出原文与改写的对比。

## 不适用场景

- 仅凭题目生成事实结论，或补造数据、访谈、案例、文献和因果关系。
- 替代资料研究、实验验证或事实核验。
- 将证据不足的判断改得更强，或删掉影响结论成立范围的真实不确定性。
- 承诺绕过 AI 检测。

## 输入与输出

建议提供待处理段落、体裁与章节位置、前后文，以及必须保留的事实、概念和技术条件。材料缺失时，技能只在已有信息范围内改写；仅提供题目时，输出标明性质的结构示范。

| 请求方式 | 输出 |
|---|---|
| 只输出改写 | 修订后的正文 |
| 诊断 | 被遮住的判断、防御性触发点、改写稿 |
| 前后对比 | 原文、改写稿，以及不超过三条关键变化 |
| 只提供题目 | 结构示范，并说明材料不足以形成事实结论 |

## 调用示例

### 直接润色

```text
使用 $chinese-academic-clarity 润色下面的段落，只输出改写。
保留所有数据、技术条件和真实不确定性。
【粘贴正文及必要上下文】
```

### 诊断段落

```text
使用 $chinese-academic-clarity 诊断这一段，分别给出被遮住的判断、防御性触发点和改写稿。
【粘贴段落，并说明它在全文中的位置】
```

### 前后对比

```text
使用 $chinese-academic-clarity 对下面的技术论述做前后对比。
保留原文，给出改写稿，用不超过三条说明关键变化。
【粘贴正文】
```

也可在任务中直接指定本目录下的 `SKILL.md`。

## 依赖与限制

该技能是文本写作规则，本身不依赖外部服务或可执行脚本。`agents/openai.yaml` 提供显示名称和默认调用提示。

处理 Word 等文件时，还需使用相应文档工具完成文件编辑与排版检查。技能只调整段落表达，不自动开展文献检索、事实核验或实验测试。

改写保留真实冲突、反例、负面结果和必要边界；实测数据、推论及待验证关系保持各自的信息强度。
